# Security Policy

## Supported versions
The `main` branch and latest tagged release are supported.

## Reporting a vulnerability
Do not open a public issue for security-sensitive reports.
Email the repository owner or open a private security advisory on GitHub.

## Scope
- Secrets accidentally committed to the repo
- Unsafe script execution in validation tooling
- Supply-chain issues in website dependencies

## Non-scope
Prompt content quality debates and GTM strategy disagreements are not security issues.
