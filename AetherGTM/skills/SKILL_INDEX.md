# AetherGTM Skill Index

AetherGTM now includes 80 executable skill files across core, product marketing, demand generation, sales, RevOps, customer success, partnerships, pricing, enablement, analytics, and forge. Each skill follows the six-layer standard and supports markdown, JSON, and hybrid output modes.

## Expansion Target
The 80-skill starter pack is the seed library. Use `/skill-forge expand domain=<domain> count=<number> quality=production output=files` to generate the remaining 420+ skills toward the 500+ target.
