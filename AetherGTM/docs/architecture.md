# Architecture

AetherGTM is layered:

1. **Context** — durable company truth
2. **Skills** — atomic executable prompt specs
3. **Workflows** — multi-phase operating motions
4. **Agents** — specialist charters
5. **Templates** — reusable deliverable shells
6. **Forge** — expansion engine
7. **Tooling** — validators, catalog, CI, website

Data flows downward: context grounds skills; skills power workflows; workflows may delegate to agents; all emit hybrid artifacts.
