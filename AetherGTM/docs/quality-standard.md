# Quality Standard

## Non-negotiables
1. Six-layer skill structure
2. Explicit triggers and versions
3. Facts vs assumptions separation
4. Hybrid output support
5. Ethical GTM constraints
6. Revenue relevance

## Review checklist
- [ ] Trigger is unique and slash-safe
- [ ] Context auto-load list is correct
- [ ] Output JSON schema is valid and useful
- [ ] Examples are realistic
- [ ] No secrets or customer data hard-coded
